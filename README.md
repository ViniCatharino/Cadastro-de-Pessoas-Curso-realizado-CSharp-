
# 💻 CRUD Console - C#

Aplicação desenvolvida em **C#** como projeto de estudos, com o objetivo de colocar em prática os conceitos da linguagem, Programação Orientada a Objetos (POO) e integração com banco de dados SQL Server.

O projeto consiste em um sistema simples de cadastro de pessoas, executado via Console, permitindo realizar operações de inclusão, consulta, alteração e exclusão de registros.

## 🚀 Objetivos do projeto

Este projeto surgiu durante meus estudos de C#, como uma oportunidade de transformar o conhecimento adquirido em prática.

A proposta também tem um significado especial: quando comecei minha jornada na programação com Delphi, desenvolvi uma aplicação semelhante, também em Console. Agora, revisitar essa ideia utilizando C# foi uma maneira de acompanhar minha própria evolução como desenvolvedor e explorar uma nova tecnologia.

## ⚙️ Funcionalidades

- ➕ **Adicionar pessoas:** cadastrar novos registros.
- 🔎 **Consultar pessoas:** visualizar os registros armazenados.
- ✏️ **Alterar pessoas:** atualizar informações de cadastros existentes.
- 🗑️ **Excluir pessoas:** remover registros cadastrados.

## 🛠️ Tecnologias utilizadas

- **C#** – Linguagem de programação.
- **.NET** – Plataforma de desenvolvimento.
- **SQL Server** – Banco de dados utilizado para persistência das informações.
- **Programação Orientada a Objetos (POO)** – Aplicação dos conceitos de orientação a objetos.

## ▶️ Como executar o projeto

1. Clone este repositório:

   ```bash
   git clone https://github.com/SEU-USUARIO/SEU-REPOSITORIO.git
   ```

2. Abra a solução no Visual Studio ou na IDE de sua preferência.

3. Configure a conexão com o SQL Server conforme as configurações do projeto.

4. Certifique-se de que o banco de dados e as tabelas necessárias estejam criados.

5. Execute a aplicação.
